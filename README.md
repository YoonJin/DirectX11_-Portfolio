 DirectXProject00 — DirectX 11 2D 렌더링 프레임워크 작업기

> **DirectX 11 을 밑바닥부터** 쌓아 올린 2D 스프라이트 렌더링 프레임워크입니다.
> Windows SDK 외 의존성 없음, Win32 + D3D11 + WIC 만으로 작성했습니다.
> 목표 직무는 **고정 논리 해상도 기반 2D 스프라이트 게임(던전앤파이터류)의 클라이언트/엔진 프로그래머**라서,
> 화려한 기능보다 **"해상도가 바뀌어도 게임 좌표계는 흔들리지 않는 기반"** 과 **"드로우콜을 줄이는 2D 배칭"** 을 만드는 데 집중했습니다.


프로젝트에 대한 설명은 https://github.com/YoonJin/DirectX11_-Portfolio/wiki 를 참고해 주세요!


포트폴리오 영상은 mp4파일로 demo 폴더에 들어가 있습니다.
